# Module 5 — Git and GitHub from the Command Line

!!! info "At a glance"

    **Time:** 5 hours (3 sessions)  
    **Labs:** Lab 08 · Git & GitHub  
    **Prerequisites:** Modules 1–4 and a free GitHub account

## What you will be able to do

- Explain repository, commit, branch, remote and merge
- Configure Git for WSL
- Record history: `status`, `add`, `commit`, `log`, `diff`
- Keep data, outputs and secrets out with `.gitignore`
- Branch, merge, and resolve a conflict
- Authenticate to GitHub with SSH keys
- `push`, `pull`, `fetch`, `clone`
- Build a professional repository

## Topics

- Git vs GitHub; working directory, staging area, commits
- `init clone status add commit log diff`
- `.gitignore` and good commit messages
- `branch switch merge`; resolving conflicts
- SSH keys: public vs private; testing authentication
- `remote push pull fetch`
- README, LICENSE, `environment.yml`, `src/ scripts/ data/ results/ docs/`
- Undoing things safely

## Check your understanding

Try these after the labs. Discuss your answers in class.

1. Git vs GitHub: one sentence each.
2. What is the staging area for?
3. When exactly does a merge conflict happen?
4. Which SSH key file goes to GitHub?
5. Name three things that belong in `.gitignore`.
6. `git fetch` vs `git pull`?

!!! tip "Stuck?"
    Read the last line of the error first, then check the [troubleshooting cheat sheet](../cheat_sheets/troubleshooting.md). Still stuck after 15 minutes? Ask, and bring the exact command and the full error text.
