# Module 8 — Capstone Project

!!! info "At a glance"

    **Time:** 10 hours (5 sessions) + independent work  
    **Labs:** Lab 11 · Capstone workshop  
    **Prerequisites:** All previous modules

## What you will be able to do

- Organise a project and its Conda environment
- Fetch raw data and verify it with checksums
- Inspect the data from the command line and document it
- Write a Bash pipeline for QC and preprocessing
- Write a tested Python analysis program
- Produce statistics, figures, logs and a report
- Version-control it systematically and push it to GitHub
- Make it reproducible for a stranger

## Topics

- Project brief and rubric
- Milestones with weekly check-ins on GitHub
- Peer reproducibility review via GitHub issues
- Release tag `v1.0` and a 5-minute live demo
